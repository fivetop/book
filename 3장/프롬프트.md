# 3장. 스킬: 업무 매뉴얼 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

## ⑥ Claude에게 물어볼 질문

**사규와 매뉴얼이 다를 때**

```
이번 일에서 사규(CLAUDE.md)와 매뉴얼 중 무엇을 따랐어? 둘이 다른 곳이 있었다면 어떻게 골랐는지 알려 줘.
```

**내 일에서 매뉴얼 찾기**

```
내가 자주 하는 일을 적어 줄게. 그중 매번 같은 순서로 하는 일을 골라 줘. 고른 일마다 매뉴얼 표지(description) 한 줄을, 내가 부탁할 때 쓸 만한 말로 써 줘. 본문은 아직 쓰지 마.
```
