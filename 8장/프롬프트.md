# 8장. 나눠 맡기기 vs 같은 일 따로 시키기 — 분업과 교차 검증 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
회의록은 회의마다 minutes-writer 에이전트 하나에게 하나씩 맡겨 줘(회의록-1.md ~ 회의록-4.md). 넷이 다 쓰면, 너는 녹취는 열지 말고 회의록 넷만 보고 신입 교육 준비 현황을 한 장으로 정리해 준비현황.md로 저장해 줘.
```

---

## ⑥ Claude에게 물어볼 질문

**이음매 따라가기**

```
준비현황.md에서 날짜, 담당, "확정"이나 "승인" 같은 말이 들어간 줄을 모두 골라 줘. 줄마다 그 말이 회의록 몇 번의 어디에서 왔는지 찾고, 이번에는 녹취도 열어서 녹취에서는 뭐라고 했는지 나란히 적어 줘. 세 곳에서 말이 달라진 줄만 따로 모아 줘.
```

**내 일의 이음매 찾기**

```
이 일은 [누가 → 누가 → 누가] 순서로 서류가 넘어왔어. 넘길 때마다 바뀌기 쉬운 것이 무엇인지 알려 줘. 특히 앞 사람이 비워 둔 것, 앞 사람이 짐작으로 채운 것이 뒤에서 어떻게 보일지 짚어 줘.
```
