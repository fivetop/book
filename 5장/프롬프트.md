# 5장. 양식으로 받기: 합치려면 양식이 같아야 한다 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
회신 세 개를 합쳐서 팀장님께 올릴 야유회 준비 확인표를 만들어 확인표.md로 저장해 줘.
```

---

## ⑥ Claude에게 물어볼 질문

**내 일의 확인표 양식 만들기**

```
이 폴더의 회신들을 한 장으로 합쳐 보고하려고 해. 바로 합치지 말고, 먼저 어떤 칸이 있는 양식이면 좋을지 제안해 줘. 회신마다 그 칸을 채울 수 있는지, 못 채우는 칸은 무엇인지도 알려 줘.
```

**흐린 말 찾기**

```
이 회신들에서 "아마", "~할 수도", "~준다고 함"처럼 확정이 아닌 말을 모두 찾아 줘. 줄마다 원래 문장, 확정처럼 읽힐 위험, 누구에게 무엇을 다시 물어야 하는지를 표로 정리해 줘.
```
