# 준비 확인표 만들기 매뉴얼

## 순서
1. 회신을 하나씩 읽고, 확인된 것을 항목 하나에 한 줄로 뽑는다.
2. 줄마다 아래 양식의 다섯 칸을 모두 채운다. 빈 칸을 두지 않는다.
3. 회신끼리 같은 항목을 다르게 말하면 둘 다 적는다.
4. 상태가 "확정"이 아닌 줄을 모두 "확인할 것"에 모은다.

## 원칙
- 회신에 없는 것은 쓰지 않는다.
  (확인표는 "확인된 것"의 표다. 짐작이 섞이면 표 전체를 믿을 수 없다.)
- "아마", "~할 수도", "~준다고 함" 같은 말이 있으면 상태는 "미정"이다.
  (말로 들은 약속은 아직 확인이 아니다.)
- 확인한 날은 회신에 적힌 날을 쓴다.
  (남은 자리, 요금 같은 것은 날이 지나면 바뀐다.)

## 양식

## 준비 확인표
| 항목 | 결과 | 상태 (확정 / 가예약 / 미정) | 출처 | 확인한 날 |

## 확인할 것
(상태가 확정이 아닌 줄. 누구에게 무엇을 물어야 하는지까지)
