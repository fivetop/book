# 11장. 말로 내 팀 만들기 — 내 판단 기준을 하네스로 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습 · 첫 번째 말

```
회의 녹취로 신입 교육 준비 현황을 한 장 만들어 팀장님께 올리는 일을, 매달 녹취가 바뀔 때마다 다시 하려고 해. 다음에도 그대로 쓸 수 있게 Claude Code 하네스로 만들어 줘. 에이전트를 나눌지 말지, 몇 명으로 할지는 네가 정하고 이유를 말해 줘. 일은 이래. 회의록은 회의마다 따로 쓰고, 현황은 그 회의록을 모아서 만들어. 녹취에 없는 것은 지어내지 말고, 팀장님께는 꼭 물어야 할 것만 맨 위에 올려 줘. 꼭 물어야 할 것은 세 가지야. 회의마다 말이 다른데 바꾼다는 말이 없는 것, 결정한 이유가 앞 회의와 맞지 않는 것, 교육 날 사람이나 물건이나 자리가 모자라거나 늦을 수 있는 것. 하네스 파일까지만 만들고 멈춰. 돌리는 건 내가 파일을 보고 나서 할게.
```

## ③ 말로 하는 실습 · 두 번째 말

```
하네스대로 회의 녹취 네 개로 신입 교육 준비 현황을 만들어 줘.
```

---

## ⑥ Claude에게 물어볼 질문

**하네스에 박힌 이번 재료 찾기**

```
.claude 폴더와 CLAUDE.md의 하네스 파일을 모두 읽고, 예시나 설명 가운데 이 폴더의 회의 녹취 내용과 닮은 것을 모두 찾아 줘. 녹취의 어느 줄과 닮았는지 나란히 적어 줘. 그리고 다음 달 녹취에도 맞도록 바꾼다면 어떻게 바꿀지 제안해 줘.
```

**자물쇠가 필요한 곳 찾기**

```
이 하네스에서 "~하지 않는다", "~할 때만 연다"처럼 말로만 막아 둔 규칙을 모두 찾아 줘. 그 가운데 tools 줄이나 폴더 위치로 막을 수 있는 것과, 말로밖에 막을 수 없는 것을 나눠 줘.
```

**내 일로 하네스 만들기**

```
나는 [ ]을 [얼마나 자주] 하고, 결과는 [누구]에게 올려. 다음에도 그대로 쓸 수 있게 Claude Code 하네스로 만들어 줘. 에이전트를 나눌지 말지, 몇 명으로 할지는 네가 정하고 이유를 말해 줘. 결과를 받는 사람에게 꼭 물어야 할 것은 [내 기준]이야. 하네스 파일까지만 만들고 멈춰.
```
