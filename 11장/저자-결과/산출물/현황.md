# 7월 신입 사원 교육 준비 현황 — 7월 8일 회의 기준

> 근거: 4회 회의 녹취(6월 17일 ~ 7월 8일). 녹취에 없는 내용은 적지 않았습니다.

## 여쭐 것 (4건)

1. **[당일 부족·지연] 노트북이 한 대 모자라고, 도착과 세팅이 같은 시각입니다** (셈: 인원 7 − 정한 수량 6 = 1대 부족 / 도착 15일 오후 = 세팅 첫날(15일) 오후)
   근거: [2회] 최 팀장: "네, 여섯 대." / [3회] 이 주임: "그래서 일곱 명이에요." / [4회] 정 사원: "전산팀에서 15일 오후에 가져다준대요."
   → 노트북은 여섯 대 그대로인가요, 일곱 대인가요? 15일 오후 도착·15일 오후 세팅이 같은 시각인데 이대로 갈까요?

2. **[말이 다름 · 당일 부족·지연] 둘째 날(16일) 장소가 3회 "소회의실"에서 4회 "사흘 다 대회의실"로 바뀌었는데 바꾼다는 말이 없습니다. 3회에는 16일 대회의실에 임원 회의가 잡혔다고 했습니다**
   근거: [3회] 박 대리: "16일에 대회의실에 임원 회의가 잡혀서 둘째 날만 7층 소회의실로 옮겨 달래요." / [3회] 최 팀장: "그럼 둘째 날만 소회의실. 나머지는 대회의실." / [4회] 박 대리: "장소는 사흘 다 대회의실이고요."
   → 둘째 날은 7층 소회의실(정원 여덟 명: 교육생 7 + 강사 1 = 8, 여유 0)인가요, 대회의실인가요?

3. **[말이 다름] 예산이 2회 320에서 3회부터 300으로 바뀌었는데 바꾼다는 말이 없습니다**
   근거: [2회] 최 팀장: "올해는 외부 강사 없으니까, 320으로 갑시다." / [3회] 최 팀장: "예산은 300 안에서 맞추고요."
   → 예산 기준은 320인가요, 300인가요?

4. **[이유가 앞과 다름] 점심을 "구내식당 공사 때문에" 도시락으로 정했는데, 2회에는 공사가 7월 21일부터라 교육 주간은 괜찮다고 했습니다**
   근거: [2회] 박 대리: "구내식당 공사 알아봤는데, 7월 21일부터래요. 교육 주간은 괜찮아요." / [4회] 김 과장: "점심은 도시락으로 하기로 했죠? 구내식당 공사 때문에." / [4회] 최 팀장: "어… 그랬나? 그럼 도시락으로 하죠."
   → 점심은 도시락인가요, 구내식당인가요?
