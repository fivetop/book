# 1장. 좋은 지시: 결론, 양식, 범위 (양식을 정하면 비용도 준다) — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습 · 1단계: "해줘"만

```
야유회-메모.md를 읽고 팀장님께 올릴 보고서를 써서 1단계-보고서.md 파일로 저장해 줘.
```

---

## ③ 말로 하는 실습 · 2단계: + 결론에 꼭 들어갈 것

```
야유회-메모.md를 읽고 팀장님께 올릴 보고서를 써서 2단계-보고서.md 파일로 저장해 줘.

이 야유회의 목적:
- 모두가 행복한 시간이 되어야 한다.

결론에는 반드시 아래가 들어가야 한다.
1. 추천 장소 하나와 이유
2. 1인 비용, 그리고 예산 15만 원을 넘는지 (메모에 있는 숫자로만)
3. 18명 모두 함께할 수 있는 활동인지
4. 팀원 의견("등산은 힘들다", "바다가 차갑다")을 어떻게 반영했는지
```


---

## ⑥ Claude에게 물어볼 질문

**내 메모의 빈칸 찾기**

```
이 메모로 보고서를 쓰려고 한다. 보고서를 쓰지 말고, 결론을 내리는 데 필요하지만 메모에는 없는 정보를 찾아 줘.
```

**내가 안 적은 사정 찾기**

```
이 메모를 보고, 결론을 바꿀 수 있는데 내가 메모에 안 적었을 만한 사정이 있을지 나에게 물어봐 줘.
```

**내 양식 고치기**

```
## 결론
## 후보 비교표
## 팀원 의견
## 확인할 것
## 다음 할 일
```
