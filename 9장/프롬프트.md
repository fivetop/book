# 9장. 서류로 소통한다 — 계획 파일, 공유 게시판, 옆길은 언제 (MultiAgent-Claude) — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
작업지시.md대로 해 줘. 회의록은 minutes-writer 에이전트 넷에게 회의 하나씩 맡기고, 준비현황은 네가 합쳐.
```

---

## ⑥ Claude에게 물어볼 질문

**넘긴 말과 서류 견주기**

```
방금 회의록 담당에게 일을 맡길 때 넘긴 말을 그대로 보여 줘. 작업지시.md와 견주어서, 더한 것, 뺀 것, 바꾼 것을 알려 줘.
```

**41개를 줄여 보기**

```
준비현황.md의 "확인할 것" 가운데, 교육 첫날 전에 정하지 않으면 교육이 틀어지는 것만 골라 줘. 왜 그런지 한 줄씩 적어 줘. 나머지는 부록으로 내려 줘.
```

**내 일의 작업지시서**

```
내가 자주 맡기는 일 하나를 여러 사람이 나눠 한다고 생각하고, 모두가 먼저 읽을 작업지시서 한 장을 같이 써 줘. 넘기는 서류에 꼭 있어야 할 칸도 제안해 줘. 일은 [ ]야.
```
