# 말로 하는 클로드 AI — 예제 파일

책 『말로 하는 클로드 AI』(부제: 멀티에이전트! 말로 만들어서 사용하는)의 실습 폴더입니다.

## 받는 법

1. 이 페이지 위쪽의 초록색 **Code** 단추 → **Download ZIP**
2. 받은 `book-main.zip`을 압축 풀기
3. 폴더 이름을 `책예제`로 바꾸고 **문서** 폴더로 옮기기

그러면 1장 실습 폴더는 `문서\책예제\1장\실습`이 됩니다. 다른 곳에 두어도 됩니다. 자세한 안내는 책 0장 "준비"에 있습니다.

## 실습 환경

Windows + Claude Pro 요금제 + 터미널에서 실행하는 Claude Code

## 폴더

장마다 `실습` 폴더가 하나 있습니다. **그 장의 `실습` 폴더에서 Claude Code를 엽니다.**

`프롬프트.md`에는 그 장에서 Claude에게 넣는 문장을 책에 나오는 순서대로 모아 두었습니다. 코드 칸을 통째로 복사해 붙여 넣으면 됩니다. 이 파일은 `실습` 폴더 **밖에** 둡니다. 안에 넣으면 Claude가 이 파일까지 읽습니다.

`저자-결과` 폴더에는 저자가 실습을 돌렸을 때 Claude가 만든 결과가 그대로 들어 있습니다. 책에서 줄여 실은 결과의 전체도 여기 있습니다. 내 결과와 견주어 볼 때 펼쳐 보세요.

| 장 | 실습 폴더에 든 것 |
|---|---|
| 1장 | 야유회 메모 |
| 2장 | 사규(`CLAUDE.md`), 복합기 메모 |
| 3장 | 사규, 업무 매뉴얼(스킬), 야유회 일정 메모 |
| 4장 | 일정표. `4장/준비`에는 연습용 가상 업체 창구(MCP)를 차리는 매뉴얼과 창구 프로그램(`server.ps1`)이 있습니다 |
| 5장 | 확인표 매뉴얼, 업체 회신 세 장 |
| 6장 | 7월 신입 교육 준비 회의 녹취 넷 |
| 7장 | 녹취 넷, 6장에서 나온 회의록 넷과 준비현황, 검토 담당 |
| 8장 | 녹취 넷, 회의록 담당 |
| 9장 | 녹취 넷, 회의록 담당, 작업지시서 |
| 10장 | 9장 폴더 + 기준표 |
| 11장 | 녹취 넷만 (하네스는 직접 만듭니다) |
| 12장 | 하네스, README, 처음 보는 9월 녹취 넷 |

## 주의

- `.claude` 폴더는 지우지 마세요. 사규, 매뉴얼, 담당자 파일이 들어 있습니다.
- 실습이 끝나면 Claude가 만든 파일이 `실습` 폴더에 남습니다. 같은 장을 다시 하려면 그 파일을 폴더 밖으로 옮기거나, 압축을 다시 풀어 처음 상태로 돌립니다.
- 같은 실습도 돌릴 때마다 결과가 조금씩 다릅니다. 책과 다르다고 틀린 것은 아닙니다.
