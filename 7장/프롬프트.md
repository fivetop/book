# 7장. 쓰는 사람과 검토하는 사람 — 떼어 놓아야 보인다 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
reviewer 에이전트에게 준비현황.md와 회의록-1.md ~ 회의록-4.md를 회의 녹취 네 개와 대조해 검토하게 해 줘. 검토 결과는 검토결과.md로 저장하고, 다른 파일은 고치지 마.
```

---

## ⑥ Claude에게 물어볼 질문

**검토자에게 무엇을 넘겼는지 보기**

```
방금 reviewer에게 일을 맡길 때 넘긴 말을 그대로 보여 줘. 내가 한 말과 다른 곳이 있으면 어디가 왜 다른지도 알려 줘.
```

**무게를 다시 달기**

```
검토결과.md의 항목 가운데, 이 현황을 받은 사람이 그대로 믿고 움직이면 문제가 되는 것을 골라 줘. 예를 들어 맡은 적 없는 일을 맡았다고 알게 되는 사람이 있는지 봐 줘. 심각도를 그 기준으로 다시 매겨 줘.
```
