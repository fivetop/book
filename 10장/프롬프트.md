# 10장. 다를 때의 기준과 멈춤 — 원본 대조, 최대 몇 번 (ex-06, 번역 작업) — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
작업지시.md대로 해 줘. 회의록은 minutes-writer 에이전트 넷에게 회의 하나씩 맡기고, 준비현황은 네가 기준표.md에 대어 보고 합쳐.
```

---

## ⑥ Claude에게 물어볼 질문

**기준표의 빈 곳 찾기**

```
준비현황.md에서 "어느 줄에도 걸리지 않았다"고 적은 것들을 모아 봐 줘. 이것들을 다 담으려면 기준표에 어떤 줄이 더 있어야 할지 제안해 줘. 다만 줄을 더하면 "팀장님께 물을 것"이 몇 개로 늘어날지도 함께 알려 줘.
```

**내 기준표 쓰기**

```
내가 자주 하는 일은 [ ]이고, 결과를 받는 사람은 [ ]야. 그 사람이 "이건 나한테 물어봤어야지"라고 할 만한 것과 "이런 건 알아서 해"라고 할 만한 것을 나눠서, 기준표 초안을 다섯 줄 안으로 써 줘. 말을 보는 줄과 일을 보는 줄을 둘 다 넣어 줘.
```
