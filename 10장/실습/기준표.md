# 기준표: 회의록끼리 다를 때, 빈칸이 있을 때

합치는 사람은 회의록 넷을 다 읽은 뒤, "확인할 것"이 될 만한 것을 하나씩 아래 표에 대어 본다. 위에서부터 대어 보고, 처음 걸리는 줄을 따른다.

| 이럴 때 | 이렇게 |
|---|---|
| 회의마다 말이 다른데, 바꾼다는 말이 없다 | 멈추고 묻는다 |
| 결정의 이유가 앞 회의와 맞지 않는다 | 멈추고, 이유가 맞지 않는다는 것과 함께 묻는다 |
| 교육 날 사람·물건·자리가 모자라거나 늦을 수 있다 | 멈추고 묻는다 |
| "금요일까지 답 없으면" 같은 조건이 붙었다 | 멈추지 않는다. 그날 확인할 것으로 둔다 |
| 일에 상관없는 빈칸 (연도, 회의 시각 같은 것) | 멈추지 않는다. 맨 뒤 부록으로 |
| 어느 줄에도 걸리지 않는다 | 확인할 것으로 두고, 어느 줄에도 걸리지 않았다고 적는다 |

"멈추고 묻는다"는 합치는 사람이 정하지 않고 팀장님께 묻는다는 뜻이다.
