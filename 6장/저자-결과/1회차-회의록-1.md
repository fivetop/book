# 회의록 (1회) — 7월 신입 사원 교육 준비

| 항목 | 내용 |
|---|---|
| 일시 | 6월 17일(화) 오전 10시 |
| 참석 | 최 팀장, 김 과장, 박 대리, 이 주임, 정 사원 |
| 안건 | 7월 신입 사원 교육 준비 |
| 다음 회의 | 6월 24일(화) |

## 1. 배경

- 인사팀이 올해도 우리 팀에 신입 교육 운영을 요청함.
- 7월 입사 신입 **6명** (작년보다 많음).
- 교육 기간은 작년처럼 **3일**.

## 2. 논의 및 결정 사항

| 주제 | 논의 내용 | 결과 |
|---|---|---|
| 교육 일정 | 처음에는 7월 둘째 주 월·화·수로 정함. 그 뒤 이 주임이 인사팀 메일 내용을 보고함: 입사일이 **7월 15일(화)로 연기**됨(내부 결재 중, 미확정). 입사 전에는 교육을 할 수 없음. | **잠정:** 셋째 주 화·수·목. 인사팀 결재가 나오면 확정 |
| 장소 | 작년에는 본사 대회의실을 사흘 동안 써서 다른 팀이 불편해함. 외부 연수원도 검토 대상(이 주임 기억으로는 하루 약 50만 원, 정확하지 않음). | **미결.** 다음에 다시 논의 |
| 예산 | 작년 수준으로 하기로 함. 작년 금액이 300인지 350인지 불확실함. | 기준 금액 **미정.** 작년 정산서를 확인해서 맞추기로 함 |
| 노트북 | 정 사원: 작년에 전산팀 지급이 늦어 첫날 노트북이 없었고, 실습을 거의 못 함. | 재발 방지가 필요하다는 데 공감함. **담당자는 정하지 않음** |
| 강사·진행 | 1일차 회사 소개: 최 팀장 / 2일차 업무 시스템 교육: 김 과장 / 3일차 부서 견학 + 선배 대화: 박 대리가 구성 | 결정. 견학 부서는 박 대리가 정해 팀장에게 보고 |
| 교재 | 작년 교재를 쓰되, 업무 시스템 화면이 일부 바뀌어 수정이 필요함 | 고쳐서 사용. 2일차 부분은 김 과장이 수정 |
| 점심 | 작년처럼 구내식당을 쓰자는 의견이 나옴. 정 사원이 7월에 구내식당 공사가 있다는 공지를 언급함 | **미결.** 공사 일정 확인 필요 |

## 4. 미결 사항

1. 교육 날짜 확정(인사팀 결재 대기)
2. 교육 장소(대회의실 또는 외부 연수원)
3. 예산 기준 금액
4. 노트북 지급 담당자
5. 점심(구내식당 공사 여부)
