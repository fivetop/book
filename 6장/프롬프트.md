# 6장. 한 명이 다 하면 생기는 일 — 내가 채운 빈칸은 안 보인다 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## ③ 말로 하는 실습

```
회의 녹취 네 개를 보고, 회의마다 회의록을 따로 쓰고(회의록-1.md ~ 회의록-4.md), 마지막에 신입 교육 준비 현황을 한 장으로 정리해 준비현황.md로 저장해 줘. 다 끝나면 스스로 검토해서 빠진 게 없는지 확인하고 보고해 줘.
```

---

## ⑥ Claude에게 물어볼 질문

**채운 것 찾게 하기**

```
네가 쓴 회의록과 준비현황에서, 녹취에 그대로 나오지 않는데 네가 채운 것을 모두 찾아 줘. 담당자, 기한, 숫자의 단위, "승인"이나 "확정" 같은 말을 특히 봐 줘. 녹취 파일을 다시 열어서, 줄마다 녹취에서 그 말이 나온 곳을 옮겨 적고, 없으면 "녹취에 없음"이라고 적어 줘.
```

**내 일에서 "채운 것" 찾기**

```
이 폴더의 원본과 정리본을 비교해서, 정리본에만 있고 원본에는 없는 말을 모두 찾아 줘. 사람 이름, 날짜, 숫자, "결정", "승인", "담당" 같은 말을 특히 봐 줘. 줄마다 원본의 어디에 근거가 있는지, 없으면 "근거 없음"이라고 적어 줘.
```
