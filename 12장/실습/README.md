# 교육 준비 현황 하네스

회의 녹취로 회의록과 팀장님께 올릴 준비 현황 한 장을 만드는 하네스다. 교육이 있을 때마다 녹취 폴더만 바꿔 다시 돌린다.

## 이번에 할 일

- 녹취: `녹취/9월/` (9월 경력직 입사자 교육 준비 회의 네 번)
- 만드는 것: 회의록(회의마다), 대조표, 현황 한 장, 검증 결과

## 돌리는 법

이 폴더에서 Claude Code 창을 열고 이렇게 말한다.

```
README.md대로 해 줘.
```

Claude는 `training-status` 스킬을 `녹취/9월`로 돌린다. 사람이 `/training-status 녹취/9월`을 직접 쳐도 같다.

## 들어 있는 것

| 파일 | 무엇 |
|---|---|
| `CLAUDE.md` | 모든 단계에 공통인 규칙. Claude가 창을 열 때 저절로 읽는다 |
| `.claude/skills/training-status/` | 순서, 판정 기준, 양식 |
| `.claude/agents/` | 회의록 담당, 검증 담당 |
| `녹취/` | 달마다 녹취를 폴더로 넣는다 |
| `산출물/` | 돌린 날짜별로 결과가 생긴다 |

## 지킬 것

- 하네스 파일(`CLAUDE.md`, `.claude/`)은 돌리는 중에 고치지 않는다. 고칠 곳이 보이면 적어 두고, 돌린 뒤에 고친다.
- 현황은 팀장님께 바로 보내지 않는다. 열어서 확인한 뒤 사람이 보낸다.

## 끝나면 볼 것

- `산출물/<날짜>/현황.md` 맨 위 "여쭐 것"
- `산출물/<날짜>/검증.md` (PASS / FAIL, 애매함)
- 보고에 "고칠 곳"이 있으면 그것
