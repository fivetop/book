# 9월 경력직 입사자 교육 준비 현황 — 9월 9일 회의 기준

> 근거: 4회 회의 녹취(8월 19일 ~ 9월 9일). 녹취에 없는 내용은 적지 않았습니다.

## 여쭐 것 (5건)

1. **[당일 부족·지연] 인원은 여섯 명으로 늘었는데 출입증은 다섯 장만 신청됨 (6 − 5 = 1장 부족 가능)**
   근거: [2회] 정 사원: "총무팀에 다섯 장." / [3회] 이 주임: "한 분이 더 붙어서 여섯 명이에요." / [4회] 정 사원: "총무팀에서 11일에 나온대요."
   → 출입증을 여섯 장으로 맞출까요, 다섯 장 그대로 둘까요?

2. **[당일 부족·지연] 첫날(16일) 사회인 박 대리가 예비군 훈련으로 빠질 수 있는데, 대신할 사람이 정해지지 않음**
   근거: [2회] 최 팀장: "진행은 박 대리가 해 줘요. 첫날 사회." / [3회] 박 대리: "16일에 예비군 훈련 통지가 왔어요. 그날 하루 빠져야 할 것 같아요." / [3회] 최 팀장: "그건 이따 다시 얘기하죠."
   → 16일 첫날 사회를 박 대리 그대로 둘까요, 다른 분으로 정할까요?

3. **[당일 부족·지연] 보안 교육 강사 서울역 도착이 열 시인데 교육 시작도 열 시 (여유 0분, 서울역→교육장 이동 시간은 녹취에 없음)**
   근거: [3회] 박 대리: "서울역에 열 시 도착이래요." / [4회] 박 대리: "둘째 날 열 시 보안 교육 외부 강사님"
   → 둘째 날 보안 교육 시작을 열 시 그대로 둘까요, 강사 도착에 맞춰 바꿀까요?

4. **[말이 다름] 첫날 시작 시각이 열 시에서 아홉 시 반으로 바뀌었는데 바꾼다는 말이 없음 (열 시는 오전 입사 서류 처리 때문에 정한 시각)**
   근거: [2회] 최 팀장: "경력직은 첫날 오전에 인사팀 입사 서류 처리가 있대요. 열 시 시작으로 합시다." / [4회] 박 대리: "첫날 아홉 시 반 시작"
   → 첫날 시작은 열 시인가요, 아홉 시 반인가요?

5. **[이유가 앞과 다름] 실무 교육을 "정 사원 교육 날 외근" 때문에 김 과장으로 바꿨으나, 3회에 정 사원 외근은 18일(교육 다음 날)이라고 함. 정 사원의 작년 자료를 김 과장에게 넘긴다는 말도 없음**
   근거: [3회] 정 사원: "18일이에요. 교육 끝난 다음 날이라 괜찮을 것 같아요." / [4회] 김 과장: "정 사원 교육 날 외근 있다고 하지 않았어요?" / [4회] 최 팀장: "그래요? 그럼 실무는 김 과장님이 해 주세요."
   → 둘째 날 오후 실무는 정 사원인가요, 김 과장인가요?
