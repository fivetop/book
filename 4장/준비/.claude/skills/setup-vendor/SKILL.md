# 가상 업체 창구 차리기 (4장 준비)

이 매뉴얼은 4장 실습에 쓸 가상 업체 창구를 차린다. 창구는 PowerShell로 만든 작은 MCP 서버다. 독자 PC에 따로 설치할 것은 없다.

이 매뉴얼 폴더에 별첨 두 개가 있다.
- `server.ps1`: 창구 프로그램. 고치지 않는다.
- `vendor-data.json`: 업체 자료 (출발 시간, 남은 차량, 안내). 고치지 않는다.

## 순서

1. **폴더 위치를 확인한다.** 지금 폴더는 `4장/준비`다. 그 위가 `4장` 폴더다. 아래 경로는 모두 `4장` 폴더 기준이고, 명령에는 전체 경로(예: `D:\...\4장\업체창구\server.ps1`)로 바꿔 쓴다.
   - `4장/실습` 폴더가 없으면 멈추고 사용자에게 알린다.

2. **창구를 차린다.** `4장/업체창구` 폴더를 만들고, 이 매뉴얼 폴더의 `server.ps1`과 `vendor-data.json`을 그대로 복사한다.
   (창구는 실습 폴더 밖에 둔다. 안에 두면 실습 때 Claude가 창구에 묻지 않고 업체 자료 파일을 직접 열어 볼 수 있다.)
   - 이미 있으면 덮어쓴다. `reservations.log`(예약 기록)가 있으면 지운다. 실습을 처음 상태로 돌리기 위해서다.

3. **실습 폴더에 창구를 연결한다.** 작업 폴더를 `4장/실습`으로 옮긴 뒤 아래 명령을 실행한다. 경로는 전체 경로로 바꾼다.

   ```
   claude mcp add railbike -- powershell -NoProfile -ExecutionPolicy Bypass -File "<4장 전체 경로>\업체창구\server.ps1"
   ```

   (`실습` 폴더에서 실행해야 그 폴더에만 연결된다. 다른 폴더와 다른 프로젝트에는 영향이 없다.)
   - "already exists"가 나오면 같은 `실습` 폴더에서 `claude mcp remove railbike`를 먼저 실행하고 다시 추가한다.

4. **연결을 확인한다.** `4장/실습` 폴더에서 `claude mcp list`를 실행해 `railbike`가 `Connected`인지 본다.
   - `Connected`가 아니면 `server.ps1`을 직접 시험한다. 아래 한 줄을 넣었을 때 JSON 한 줄이 돌아와야 한다.
     `{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"t","version":"1"}}}`
   - 그래도 안 되면 멈추고, 무엇이 안 되는지 사용자에게 그대로 보여 준다.

5. **사용자에게 알린다.** 아래만 짧게 말한다. 업체 자료의 내용(출발 시간, 남은 차량)은 말하지 않는다. 실습에서 Claude가 창구로 알아낼 내용이기 때문이다.
   - 창구를 차렸고 `실습` 폴더에 연결했다.
   - 이 창은 닫고, `4장/실습` 폴더에서 새 창을 열어 실습을 시작한다.
   - 실습이 끝난 뒤 창구를 치우려면 `실습` 폴더에서 `claude mcp remove railbike`를 실행한다.
