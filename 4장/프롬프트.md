# 4장. MCP: 협력 창구 — 다른 부서, 업체와 연결한다 — 프롬프트

책에 나오는 프롬프트를 나오는 순서대로 모았습니다. 코드 칸을 통째로 복사해 Claude Code에 붙여 넣으면 됩니다.

- 이 파일은 `실습` 폴더 밖에 있습니다. `실습` 폴더 안으로 옮기지 마세요. Claude가 이 파일까지 읽습니다.
- `[ ]`가 있는 프롬프트는 괄호 안을 내 일로 채워서 씁니다.
- 언제 어떤 순서로 넣는지는 책을 따릅니다.

---

## 실습 전에 한 번: 업체 창구 차리기

`실습` 폴더가 아니라 **`4장\준비` 폴더**에서 Claude Code를 열고 넣습니다. 명령을 실행해도 되는지 물으면 허락합니다. "연결했다"는 말을 들으면 이 창을 닫습니다.

```
업체 창구 차려 줘.
```

---

## ③ 말로 하는 실습

`4장\실습` 폴더에서 **새 창**을 열고 넣습니다.

```
레일바이크 업체에 탈 시간을 알아보고 일정표.md를 고쳐 줘.
```

```
총무팀 이름으로 예약해 줘
```

## ⑥ Claude에게 물어볼 질문

**내 Claude에 연결된 창구 보기**

```
지금 너에게 연결된 창구(MCP 서버, 커넥터)를 모두 알려 줘. 창구마다 도구를 "묻는 도구"와 "보내는 도구"로 나눠 줘.
```

**내 일에서 창구 찾기**

```
내가 이번 주에 다른 부서나 업체에 물어본 일을 적었어. 하나씩 보고, 창구(MCP)로 연결하면 Claude가 대신 물어볼 수 있는 것과, 사람이 직접 전화하거나 찾아가야 하는 것으로 나눠 줘. 창구가 있는지 모르는 것은 누구에게 확인하면 되는지도 알려 줘.
```
